# バーの色の凡例 — モックアップ

担当者×タスク表示で担当者を全員畳んだときや、以前の表示（担当者別・段分け）のときは、行の見出しにタスク名が無く
「どの色がどの対応か」が分からない。ガントの下に凡例を出して補う案（2026-09-29 ユーザー提案）。

## 見方

`index.html` を開き、「凡例の形（札を並べる／版数でまとめる）」「表示幅（PC／スマホ）」を切り替える。
凡例の項目をクリック（PC はマウスを乗せる）すると、その対応のバーだけが濃く・ほかが薄くなる。

## 案の要点

- 凡例に出すのは、いま画面に出ている予定の対応だけ（表示範囲・フィルタに合わせて変わる）
- 並びはガントの色の割り当てと同じ（版数 → 処理名 → 対応名）
- 出す条件: 担当者を全員畳んだとき／以前の表示／タスク名が見出しに無い表示。タスクごとの行が見えている表示では出さない
- スマホは「凡例（N 件）」の見出しで開け閉め（最初は閉じる）。PC は最初から開く
- 形は 2 案: 札を並べる（コンパクト）／版数でまとめる（タスク名の見せ方「まとめる」と揃う）
