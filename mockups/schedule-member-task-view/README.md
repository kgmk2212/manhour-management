# 担当者×タスク ビュー — モックアップ

ガントの担当者別ビューで重なっていた予定を、**担当者ごとのグループの中で「版数 / 対応名」の行に分ける**案。
今の担当者別ビュー（重なりを自動の段に分ける表示・2026-09-24 導入）と同じデータで切り替えて比べられる。

## 見方

`index.html` をブラウザで開く（外部依存は Google Fonts のみ・単体で動く）。上部のボタンで表示を切り替える。

- **今の担当者別（段分け）**: 現行の表示。重なった予定は下の段に積まれるが、段が何の作業かは読めない。
- **担当者×タスク（案）**: 担当者の見出し行＋タスク行。見出し行の帯は、その人の未完了の予定の日ごとの本数
  （淡い緑 1 本／黄 2 本／橙 3 本以上。遅延中の予定は今日まで抱えているとみなす）。見出しの ▾ で畳むと帯だけ残る。

サンプルデータ・今日は 2026-09-24（木）で固定。9/21〜23 は祝日。

## 案の要点

- 表示モードは今の「担当者別／タスク別」を残し、3 つ目の「担当者×タスク」として追加する想定
- タスク行の並びは「タスク着手順」→ 開始日順。行内で重なる場合（本作業とレビュー等）は既存のレーン分割を行内で使う
- 縦ドラッグ: 別担当者のグループへ落とすと担当者変更。同じ担当者の別タスク行へは日付の移動のみ
- 割り込みドロップ（重なり時メニュー）は担当者単位のまま動く
