# タスク名の見せ方（ガントの見出し欄）— モックアップ

担当者×タスク表示（`../schedule-member-task-view/`）の見出し欄で、長いタスク名の改行位置が悪く読みにくい問題への案。
タスク名はデータ上「処理名：対応名」（古いデータは「_」区切り）なので、版数・処理名・対応名に分けて見せる。

## 見方

`index.html` を開き、「見せ方」「表示幅（PC／スマホ）」「見出し欄の幅（標準／広め）」を切り替える。
上に見出し欄の幅・タスク行の高さ・行数・表の高さ（現状との比較）を出す。

| 案 | 見せ方 | 行の高さ |
|---|---|---|
| 現状 | 1 つの文字列を文字単位で 2 行まで | 36px |
| A 3 段 | 版数 ／ 処理名 ／ 対応名（対応名は 2 行まで） | 68px |
| B 2 段 | 処理名＋版数の札 ／ 対応名（1 行、広い画面なら全部見える） | 42px |
| C 処理名でまとめる | 担当者 ＞ 処理名の見出し行 ＞ 対応名の行（2 行まで） | 38px（＋処理名の見出し行 28px） |

- 対応名の折り返しは文節の切れ目（モックアップは簡易ルール、本実装は BudouX を同梱する想定）。「現状」だけ文字単位
- 「広め」は PC で見出し欄 320px（標準 200px）、スマホは画面幅の 40%＋40px
