## 改善案の要点（現行との差分）

- **サマリ**: 数値タイル5枚 → 「**43** 件を反映します」の1行＋右側にドット付き内訳（追加/上書き/削除/変更なし）
- **エンティティ**: 横並びのチェックボックスカード＋下部に別途セクション → 実績・見積をそれぞれ1枚のカードにまとめ、
  見出し行に件数バッジ（`追加20` `現在のみ3` `変更なし105`）を並べる
- **変更行**: 既存／取込を2カラムのボックスで並置 → 1行の inline diff（`工数8・作業月2026-01 → 工数12・作業月2026-01`、
  変わった値だけ強調）
- **追加/削除の内容**: 折りたたみを開くと別ブロック → カード内にインラインで3件プレビュー＋「…ほか17件」
- **設定系**: 上部にレコード系と混在 → 末尾に「設定とAI分析」としてチェックボックスを集約
- **色**: 追加=緑地／変更=橙地／削除=赤地の領域塗りで分類を面で示す（現行は主にタグとボタン色のみ）
