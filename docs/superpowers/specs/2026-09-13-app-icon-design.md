- 作成: 2026-09-13
- 状態: 採用・実装済み

- 対象ブランチ: `claude/fable-app-icon-designs-sktsrz`（`experiment/ui-scaling` から派生、PRベースも同ブランチ）

## 1. 背景

`index.html` の favicon（`<link rel="icon">`）が `📊` 絵文字の仮置きのままだった。
Fable にブランドカラー（アクセントグリーン `#2D5A27` / アンバー `#C4841D`、`style.css` 定義）を基調にした
アイコン案を作成させ、方向性の異なる6案を `mockups/app-icon/` に用意して比較検討した。

## 2. 決定事項

**案1「時計とグラフ」を採用**。

理由: 「時間（工数）」を表す時計と「集計・分析」を表す棒グラフを組み合わせており、
本アプリの中核機能（見積 vs 実績の記録・集計）を最も直接的に表現できる。深緑の背景に
時計の針と最も伸びた棒グラフだけをアンバーにする配色で、小サイズ（favicon/タブアイコン）
でも視認性を保てる構図であることも決め手。

他案は不採用（見送り、履歴として `mockups/app-icon/` に残す）:

| 案 | 見送り理由 |
|---|---|
| 案2 ガントバー | スケジュール機能寄りの表現で、アプリ全体の代表アイコンとしては訴求範囲が狭い |
| 案3 進捗リング | 抽象度が高く、時計＋グラフ案に比べ機能連想が弱い |
| 案4 カレンダーチェック | 実績・休暇入力寄りの表現で、見積機能との連想が弱い |
| 案5 枠と実 | コンセプトは工数管理の本質を突いているが、小サイズだと二重の四角がやや潰れやすい |
| 案6 タイムシート | グリッド柄が小サイズ（16px相当）で潰れやすく favicon 向きではない |

## 3. 実装内容

- `index.html` の `<link rel="icon">` を `mockups/app-icon/icon-1-clock-chart.svg` と同一の
  インラインSVG data URI に差し替え（既存の絵文字favicon実装パターンを踏襲し、`#` は `%23`、
  `"` は `%22` にパーセントエンコード）
- 検証: ローカル静的サーバー + headless Chromium で favicon の data URI を直接レンダリングし、
  意図した配色・形状で描画されることを確認（自動テストではなく目視レンダリング確認）
- `docs/CODEMAP.md`: 差分なし（favicon行はインデックス対象外のため再生成のみ実施）

## 4. 今後の検討

- PWA向けアイコン（`manifest.json` の `icons` エントリ、`apple-touch-icon` 等）は本タスクの
  スコープ外。必要になった時点で本SVGをベースにPNG書き出しを検討する。
